Set the situation, then read the order
How to read it. Orders run A, B, C. Carry out the first one that is actually possible on your table, and drop to the next if it will not work. The ladder shows what that exact variant does at each range band, and the order follows the ladder.

Tracking. In Alpha Strike, tap the armour and structure pips and the condition updates itself. In Classic, your record sheet holds the hit locations, so just set the condition. A crippled unit gets ordered off the field either way.
