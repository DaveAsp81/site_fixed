BattleTech HQ - site-wide chrome update
=======================================

HOW TO USE THIS (no command line needed)

1. Unzip this folder OVER your local site_fixed repo folder, keeping the
   folder structure. Say yes to replacing existing files.

2. DELETE ONE FILE BY HAND:
        assets/images/mechs.html
   A zip cannot delete things. This is a stray older copy of the mech guides
   index that was sitting in the images folder. If you leave it, it stays
   live at /assets/images/mechs.html and competes with the real page in
   search. Just delete it in Explorer.

3. Open GitHub Desktop. It will list the changed files. Check a few in the
   diff view, write a commit message, commit, then Push origin.

4. After it deploys, hard refresh the site (Ctrl+F5). The stylesheet changed,
   so a cached copy will make it look like nothing happened.

DO NOT include READ-ME-FIRST.txt in the commit. Delete it, or untick it in
GitHub Desktop before committing.
